# Quarterly Access Recertification Process

This project simulates a quarterly privileged access recertification exercise we do in an enterprise CyberArk environment. This security process demonstrates how privileged access is reviewed, certified, and documented to ensure compliance with the principle of least privilege and internal security policies.


### 1. Safe Membership Review
Review of Safe members, assigned permissions, and certification decisions.

### 2. Privileged User Register
Inventory of privileged users including role, platform, last access date, and account status.

### 3. Exceptions Log
Records exceptions identified during the review along with risk ratings and remediation actions.

### 4. Sign-off Tracker
Tracks certification completion by Safe Owners and identifies outstanding reviews.
